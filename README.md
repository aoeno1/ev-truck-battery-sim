# ev-truck-battery-sim

**新能源重卡电池系统交互仿真 · 单文件 HTML 生成器**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

把一个"讲电池系统组成"的需求，做成**单文件、零依赖、离线可用、一屏操作完成**的交互仿真 HTML。点击更换电池包（磷酸铁锂 / 三元 / 固态 / 钠离子），电量、重量、续航、充电时长、温度行为实时联动。

## 成果总览

- **三态仿真**：行驶放电 / 刹车能量回收 / 热管理（制冷·制热·保温）实时切换，粒子流动表意能量流方向与大小
- **四条物理耦合链**：电量→续航（一阶）；电池重→整车重→滚阻→续航（二阶）；温度→容量衰减+温控功耗+充电倍率（三阶）；SOC 窗口+BMS 门限→实充功率（四重限流）
- **四体系数据全部对标市面公开口径**：固态 320 Wh/kg（2026 装车区间 300–380 下沿偏中）、钠电 140（电芯 175×成组 80%）、钠电 −40℃ 保持 90%+（解放 J6P 实测口径）
- **分体系充电逻辑**：只有钠离子全 SOC 窗口（5–100%）免预热快充；LFP/三元/固态关热管理快充实测约 30 分钟（仿真）即 47℃ 降流——演示最有说服力的一组对照
- **iOS 风一屏 UI**：白底商务风、系统色、8pt 栅格、悬停 tooltip、按压式踏板；三档响应式（≥1200 / 780–1199 / <780），14 视口实测零滚动
- **零依赖验证**：无头浏览器确定性回归（`__sim.step()` 钩子），4 组标准工况数值断言

## 快速开始

**看演示**：下载 [`assets/demo.html`](assets/demo.html)，双击用浏览器打开即可（无需网络、无需服务器）。

**用 skill 生成自己的版本**：将本仓库作为 skill 提供给 AI Agent，描述你的演示需求（车型、部件、电池体系、工况），Agent 会按 `SKILL.md` 的六步工作流生成同类页面。
