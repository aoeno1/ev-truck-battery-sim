# 设计决策日志（从真实对话提炼）

> 本文件记录 `ev-truck-battery-sim` 的完整需求演进：每一轮用户反馈 → 关键决策 → 依据。它展示了这个 skill 是如何从真实使用中提炼出来的，也是后来者理解"为什么这么做"的唯一材料。已脱敏。

## 第一轮 · 从 skill 调研回归真实需求

- **起点**：调研 GitHub 上同类型 skill（新能源/动力电池方向），确认现成"解剖/爆炸图"工具均为成品渲染器，非可配置的生成器。
- **决策**：放弃外部 skill，回归真实需求——展示重卡电池系统组成 + 三态运行（行驶放电/刹车回收/热管理）。
- **依据**：需求本质是"讲组成 + 讲逻辑"，不需要照片级渲染；自研单文件 HTML 最可控且符合离线交付偏好。

## 第二轮 · 升级为可交互仿真

- **反馈**：点击更换电池包（磷酸铁锂/三元/固态/钠离子），电量/续航/充电速率联动；**重量必须互相耦合**（电量多→车重→续航减）；叠加温度影响；CTB 单包设计。
- **决策**：建立三条耦合链（电量→续航一阶；重量→滚阻二阶；温度→容量+温控功耗+充电倍率三阶），状态量电池温度 Tb 独立推进。
- **依据**：用户点名"电量多了车重了续航就会减少"——二阶耦合是演示的灵魂，不可省。

## 第三轮 · 布置纠偏 + 单页化 + 踏板交互

- **反馈 ①**：液冷机组应为**集成式、置于驾驶室前进风口**，高压箱置于**座椅下**（行业常规布局）；电池包长度减 50%、内部 4 模组；所有内容一屏不滚动。
- **反馈 ②**：无用的描述不要常驻，做悬停显示；制动/加速/充电三踏板同尺寸不同色（充电功率直接选），逻辑一致；要 iOS 风格。
- **决策**：
  - 按常规布置重排——车架纵梁上方完整释放给货箱，这个收益点成为布置讲解的核心；
  - 所有静态说明收进 hover tooltip（触屏 click 触发）；
  - 弃用正负滑杆（用户反馈"难理解"），改按压式踏板 + 功率直选；
  - iOS 规范落地：系统色（#007AFF/#34C759/#5856D6）、8pt 栅格、系统字体栈。
- **依据**：一屏完成所有操作是硬约束；"同尺寸不同色"保证三个控件肌肉记忆一致。

## 第四轮 · 充电逻辑纠错 + 数据核查锁定

- **反馈 ①**：充电逻辑有错——LFP/三元/固态快充都限制 SOC 范围，钠电窗口宽；**只有钠电充电基本不需要开热管理，其他电池关了热管理快充很快温度报警**。
- **反馈 ②**：窄屏布局优化；各体系数据与市面公布数据逐项核查，基本结论先锁死（能量密度/能耗/续航/可用 SOC 区间/低温性能）。
- **决策**：
  - 引入分体系 SOC 窗口 + BMS 门限状态机（低温禁充/热报警/停充）+ 化学体系热损系数。~~钠电 −20℃ 关热管理 600kW 免预热的正例~~（此为正例的说法在第五轮被证伪，见下），与 LFP 25℃ 600kW 约 30 分钟报警的反例，成为演示最有说服力的一组对照；
  - 数据逐项对标：固态 280→**320** Wh/kg（装车区间 300–380 下沿偏中）、钠电 131→**140**（电芯 175×成组 80%）、三元 190→**200**，连带倍率与 SOC 窗口修正、固态/钠电低温曲线上调；
  - 布局改三档响应式（≥1200 / 780–1199 / <780），14 视口实测零滚动。
- **依据**：用户是电芯评测专业背景，对"逻辑错误"和"数据出处"极其敏感——模型必须同时经得起物理推演和市面对标。

## 第五轮 · 钠电低温充电口径纠偏（2026-10-24）

- **反馈**：程序有问题——**钠离子电池低温充电还是需要热管理的，常温快充需要的热管理少**。
- **根因**：代码里 `cold = (Tb < 0 && pk.key!=='na')` 把钠电整条从低温逻辑里豁免了——不禁充、不限倍率、不计预热时间，于是 −20 ℃ 直接给满 600 kW；连带 12 处文案全是"钠电免预热"口径。错误根源是把**放电侧**的低温优势（−40 ℃ 保持 90%+）误当成了**充电侧**优势。
- **物理依据**：
  - 硬碳负极平台区距 0 V 析钠阈值仅 50~100 mV，窗口比石墨更窄；
  - −20 ℃ 充电内阻可由 5 mΩ 涨到数百毫欧，充入电量只有标称的五六成；
  - −20 ℃ 0.5C 末端电位已 −0.03 V 越线；工程通行做法是 −10 ℃ 以下降倍率至 0.2C 以下，或加热到 5 ℃ 以上；
  - 钠电真正的优势是**常温快充产热约为锂系的 1/4**（同为 600 kW 快充、关液冷跑 15 min：钠电升 3.6 ℃ vs 铁锂升 12.9 ℃），因此热管理功率与冷却回路可精简。
- **决策**：
  - 低温逻辑分三层：`lockCharge`（锂系 0 ℃ 以下硬锁流 0.12）→ `needWarm`（锂系 15 ℃ / 钠电 5 ℃ 需预热）→ `derate`（电芯倍率折减，钠电 −20 ℃ 压到 0.04 ≈ 0.1C）；
  - CURVE_C 钠电段从 `[-40,.50]…[-20,.85]` 收紧为 `[-40,.016]…[-20,.04]`；
  - 预热功率口径改为"机组 PTC 18 kW + 桩侧电池预热回路合计 45 kW"（原按 18 kW 单算，LFP −20→15 ℃ 算出 135 min，偏离工程量级，修正后 54 min）；
  - 同步 demo 文案 9 处、`battery-data-bench.md` §3/§4、`physics-model.md` §3.2/§3.3/§5、`verification.md` 工况 3/新增工况 5、README/SKILL/design-decisions。
- **教训**：体系级优势不能跨维度外推——"某体系在 A 维度领先"不等于"A 维度领先能自动带到 B 维度"。这类错误在代码里往往表现为一行 `&& pk.key!=='na'` 的豁免，静态检查看不出来，只能靠静态能力探针读 `PchgMax` 真值发现。

## 第六轮 · 热管理口径澄清 + 放电侧功率折减（2026-10-24）

- **反馈（三连问）**：① 低温都需要加热？② 常温快充钠电产热少所以热管理比铁锂少？③ **放电是不是也都需要热管理？**
- **调研结论**：①②均确认（低温所有体系都需加热介入，差别在目标温度 15℃/5℃；钠电常温产热约 1/4 已实测量化）。③的答案是**放电侧无析锂/析钠安全门限（充电时负极电位才逼近 0 V），不设硬预热门限，只折功率**；但放电侧热管理诉求真实存在且方向相反——充电怕冷要加热，放电怕热要散热（常温重载爬坡 500 kW × 2% ≈ 10 kW 热负荷，液冷是重卡标配）。
- **模型缺口**：低温只折续航（CURVE_T）不折功率，`P=thr×450` 恒定——与"钠电豁免"同源的第四块缺口。
- **决策**：
  - 新增 `CURVE_P` 放电功率保持率曲线（−20℃：LFP .50 / 三元 .55 / 固态 .78 / 钠电 .80；−40℃：LFP .12 / Na .55），依据"脉冲功率衰减远比容量保持陡"与中科海钠电芯"−20℃ 1C 与 C/2 可用能量相当（高倍率自加热）"实测；
  - 行驶产热仍按踏板**请求**功率计（不用折减后功率）——低温内阻升高时同等请求功率产热更多，方向与物理一致，模型因此能复现"自加热暖机"：−20℃ 满踏板 30 min，LFP −20→−14.2 ℃、功率 225→282 kW；
  - 同步 `battery-data-bench.md` §3 新增 CURVE_P + §4 重写（含 4.2 放电行为）、`physics-model.md` 新增 §3.4、`verification.md` 增工况 6/7/8（共 7 组）、SKILL/README/design-decisions。
- **产业交叉验证（文章素材）**：一汽解放 J6P 339 kWh 官方口径"−40℃ 无需电池预热即可满功率输出"是**放电**口径；宁德时代钠新 −40℃ 90% 可用电量同为放电口径，且其在重卡上的量产落点是 24V 启驻一体（非动力电池）——两家均无 −40℃ 快充宣传，反向印证第五轮修正。
- **教训**：每一条物理链路都要单独问"低温下这条链断不断"——充电链（倍率/禁充/预热）、放电路（容量/功率/自加热）是两条独立的链，修完一条必须回头查另一条。

## 贯穿全程的方法论沉淀（本 skill 的核心）

1. **矢量 SVG 而非 AI 生图**：部件位置精确、标签不干涉、零依赖、无限清晰。对"示意图"场景，AI 生图反而更慢更不可控。
2. **量纲手算复核**：滚阻项漏乘 1000 m 距离因子导致续航虚高 3.8 倍——能量公式必须两条路径交叉验证。
3. **验证钩子先行**：headless 环境 rAF 不触发，不暴露 `__sim.step()` 就没有回归能力；60 倍单位 bug 靠轨迹回归抓出。
4. **数据先锁后写**：四个基准数错一个，全部派生结论（续航/充电时长/对比条）全错。
5. **信息分层**：静态说明悬停化、实时值仪表化、对比条归一化——一屏承载全部信息的前提。
