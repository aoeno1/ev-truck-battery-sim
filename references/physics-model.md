# 物理模型：三条耦合链

> 本文件是 `ev-truck-battery-sim` skill 的模型依据。所有系数改动必须先改本文件，再改代码。

## 1. 电量 → 续航（一阶）

```
E_可用 = E_额定 × 0.90 × η_T(化学体系, 电池温度)
续航(km) = E_可用(kWh) / 电耗(kWh/km)
```

- **可用 SOC 统一 0.90**：行业预留 5–10% 不用。
- **η_T**：温度保持率，查 `battery-data-bench.md` 的 CURVE_T。

## 2. 电池重 → 整车重 → 续航（二阶，最易漏）

```
m_电池(t) = E_额定(kWh) / 系统能量密度(Wh/kg) × 1000
m_整车(t) = m_牵引车+挂车(15 t) + m_电池
C_滚阻 = m_整车 × g × f × 1000 / 3.6e6 / η_drive      [kWh/km]
C_风阻 = 0.5 × ρ × (Cd·A) × v³ × (3600/v) / 3.6e6 / η_drive   [kWh/km]
C_附件 = P_热管理(kW) / v(km/h)                        [kWh/km]
电耗 = C_滚阻 + C_风阻 + C_附件
```

**基准系数**：`f=0.0065`（重卡子午胎滚阻）、`Cd·A=3.6 m²`、`ρ=1.2 kg/m³`、`η₀=0.90`（低温按 `1 − clamp(15−T,0,40)×0.004` 折减）、`v=80 km/h`（行业宣传等速口径）。

> ⚠️ **量纲雷区**：`F_roll × 1000` 的 1000 是"每公里 1000 m"的距离因子，漏乘则电耗小 3.8 倍、续航虚高。验证法：`F·v`（N × m/s = W）与 `P/v`（kW / km/h）两条路径必须收敛到同一电耗。

## 3. 温度 → 容量 + 温控功耗 + 充电倍率（三阶）

状态量：**电池温度 `Tb`**（独立于环境温度，由热平衡实时推进）。

### 3.1 热动力学步进

```
Ck = m_电池(kg) × 1000 × 950 / 3.6e6        [kWh/K，质量定压比热取 950 J/(kg·K)]

热源 q：
  行驶  q = P_放电 × (1 − η_drive) + P_附件
  回收  q = P_回收 × (1 − η_regen)
  充电  q = P_实充 × heat(化学体系)          ← 必须用实际充电功率，不是踏板功率
  待机  q ≈ 0

温控 rm：
  Tb > 33℃ 且开机 → 制冷 rm = 70 kW（目标 38℃）
  Tb < 17℃ 且开机 → PTC 制热 rm = −18 kW（目标 15℃）
  其间开机     → 保温循环 1 kW + 漏热 0.06 × Ck × (T_env − Tb)
  关机         → 自然对流漏热 0.045 × Ck × (T_env − Tb)

Tb ← clamp(Tb + (q − rm)/Ck × dt/60, T_env − 3, 58)
```

> ⚠️ **单位雷区**：`(q−rm)/Ck` 的单位是 **K/小时**，乘 `dt/60`（dt 为分钟）才是 K。漏除 60 会让热动力学快 60 倍（实测 10 秒冲 52℃）。

### 3.2 热损系数 `heat`（充电产热/实充功率）

| 体系 | heat | 依据 |
|---|---|---|
| LFP | 0.10 | 产热温和，快充温升可控 |
| 三元 | 0.11 | 活性最高、产热最大 |
| 固态 | 0.08 | 界面阻抗低 |
| 钠电 | **0.025** | 公开实测 5C 温升 <5℃，基本不需额外降温 |

### 3.3 BMS 门限状态机（充电）

```
窗口  socWin(pk, soc)：窗口外收流至 25%
       LFP 20–90 / 三元 20–80 / 固态 10–90 / 钠电 5–100（唯一全窗口）

低温门 cold：Tb < 0 且非钠电 → gate 0.12 涓流（析锂保护）；钠电免预热
热报警  hot  ：Tb ≥ 47℃ → gate 0.30 降流
停充    hotStop：Tb ≥ 52℃ → gate 0

P_实充 = min(E_额定 × C_倍率 × 低温折减 × 0.90, P_桩) × socWin × gate
```

冷态预估按"预热 + 回暖后速率"：`t_预热 = (15 − Tb) × 3.8` min（钠电减半）。

## 4. 仿真时间

1 秒实时 = 1 分钟仿真（60× 加速）。充电 20→80% 时长以仿真分钟计。

## 5. 三态模式

| 模式 | 能量流 | 粒子方向 | 温控策略 |
|---|---|---|---|
| 行驶放电 | PACK → 高压箱 → 电驱桥 | 正向，速度 ∝ 油门开度 × 车速 | 按 Tb 自动制冷/制热 |
| 刹车回收 | 电驱桥 → PACK | 反向 | 同上 |
| 充电 | 桩 → PACK | 反向，速度 ∝ 实充功率 | 关机快充必报警（除钠电） |
